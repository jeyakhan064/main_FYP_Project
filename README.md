✨ What is Fashion Forge?

Fashion Forge is an interactive platform where users can customize apparel in 3D, visualize unique designs, and explore AI-generated fashion ideas. Bring your creativity to life with real-time 3D rendering and smooth animations.

🚀 Features

🎨 3D Apparel Customization – Real-time modeling using Three.js & React Three Fiber.

🤖 AI Design Suggestions – Generate unique patterns with Pollinations.AI.

⚡ Interactive UI & Animations – Smooth transitions with Framer Motion.

🔒 Secure User Accounts – Authentication via JWT & bcryptjs.

💾 Save Your Designs – State persistence with LocalStorage.

☁️ Cloud Media Ready – Future integration with Cloudinary.

🛠️ Tech Stack

Frontend: React, Vite, Three.js, React Three Fiber, Drei, Valtio, Tailwind CSS, Framer Motion
Backend: Node.js, Express, Nodemon
Database: MongoDB, Mongoose
Authentication: JWT, bcryptjs, express-validator, CORS
AI & APIs: Pollinations.AI, Axios
Cloud: Cloudinary (planned)
Config: dotenv
